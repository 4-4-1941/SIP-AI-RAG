# Reglas de trabajo para cualquier IA en el proyecto SERUMS

1. Leer AGENTS.md del repo SIP-AI-RAG antes de tocar algo.
2. Mostrar el plan y esperar la confirmación "OK".
3. Entregar archivos completos, con su ruta exacta.
4. No crear agentes, carpetas ni módulos sin orden del dueño del proyecto.
5. No tocar Supabase ni auth.js sin orden explícita.
6. Verificar en los repositorios antes de afirmar algo sobre ellos.
7. Declarar lo que no se pudo verificar.
