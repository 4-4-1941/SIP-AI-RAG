# SIP-AI RAG — Fuentes documentales

## Colecciones previstas

- `knowledge/minsa/` — documentos oficiales del Ministerio de Salud del Perú.
- `knowledge/ins/` — documentos oficiales del Instituto Nacional de Salud.
- `knowledge/ops-oms/` — documentos oficiales OPS/OMS.
- `knowledge/normas/` — normas técnicas, resoluciones y documentos normativos.
- `knowledge/guias/` — guías y manuales oficiales.
- `knowledge/examenes/` — material oficial autorizado para entrenamiento.

## Metadatos mínimos

Cada documento incorporado al RAG deberá conservar:

- organismo emisor;
- título;
- fecha y versión;
- tipo de documento;
- página o sección;
- URL o procedencia;
- rol de evidencia;
- estado de vigencia cuando corresponda.

## Regla

SIP-AI no debe fabricar citas. Una fuente que demuestra uso institucional no
debe utilizarse automáticamente como fuente de puntajes, puntos de corte,
licencias o criterios diagnósticos.
