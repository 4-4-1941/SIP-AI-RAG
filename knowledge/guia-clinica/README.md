# GUIAS SALUD - JSON para RAG

Un JSON por PDF, más `manifest.json` con inventario y `README.md`. Cada JSON tiene metadatos de origen, SHA-256, cantidad de páginas, métricas de extracción y texto separado por página.

Las páginas con menos de 40 caracteres se identifican en `pages_with_little_or_no_text`; podrían requerir OCR antes de indexar.
